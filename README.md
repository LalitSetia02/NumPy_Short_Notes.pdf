# NumPy Short Notes

Quick reference notes and code examples for the Python **NumPy** library, covering essential data structures, mathematical functions, and array operations.

## Topics Covered
* **Array Creation:** Using `arange`, `zeros`, `ones`, `linspace`, `eye`, and converting lists to arrays.
* **Random Module:** Generating random numbers, integers, and using `random.seed()`.
* **Array Manipulation:** Reshaping matrices, checking shapes, finding min/max values, and index mapping (`argmax`, `argmin`).
* **Indexing & Slicing:** Accessing elements, slicing multi-dimensional arrays, and handling row/column indices.
* **Broadcasting & Mutability:** Understanding how Python stretches arrays for math operations and array mutation behavior.
* **Universal & Summary Functions:** Square roots, trigonometric functions, exponents, logs, sums, means, and axis logic (`axis=0` and `axis=1`).
